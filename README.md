# Moment 1 – TypeScript

Detta repository innehåller lösningen för **Moment 1** i kursen *DT208G – Programmering i TypeScript*.

## Funktioner
- Möjlighet att lägga till nya kurser via ett formulär.
- Kurser sparas i **localStorage**.
- Enkel validering av unika kurskoder och korrekt progression (A, B eller C).
- Responsiv design med grundläggande CSS.

## Teknik
- Byggd med [Vite](https://vite.dev) och **TypeScript**.
- Versionshantering med Git och GitHub.
